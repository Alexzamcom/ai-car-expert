# AI Car Expert

Автомобильная мультимедийная система с ИИ-помощником для **iPad Pro 12,9″**, установленного вертикально
(горизонтальная ориентация, iPhone и Android тоже поддерживаются). PWA: React + TypeScript + Vite.

**Открыть:** https://alexzamcom.github.io/ai-car-expert/ → в Safari «Поделиться» → «На экран „Домой“».

Первый тестовый автомобиль — Peugeot 3008 (1-е поколение, 2010, 1.6 THP, бензин, климат-контроль с AUTO).

## Что умеет

| --- | --- |
| **Главный экран** | карта — главный элемент; панель Музыка / ИИ / Приложения / Поездка сворачивается, разворачивается, меняется местами с картой |

| **YouTube Music** | источник в разделе «Музыка» и в приложениях: официальное приложение (на iPad — попытка открыть приложение, при неудаче — сайт music.youtube.com) с вашей учётной записью; без API и iframe; радио ставится на паузу; при возвращении — карта и маршрут на месте; честный статус (что играет в YouTube Music, приложение не видит); пауза и треки — через Пункт управления, Siri или кнопки на руле: управлять другим приложением из веб-приложения iPadOS не позволяет ([исследование](docs/MEDIA-CONTROL.md)) |

| **Оформление** | темы «День», «Ночь», «Автоматически» (по восходу и закату по геопозиции, без координат — как в системе); быстрая кнопка в верхней строке, выбор в настройках, плавная смена без перезагрузки |
| **ChatGPT по подписке** | кнопка в нижней панели открывает официальный ChatGPT (приложение по универсальной ссылке или сайт chatgpt.com) с вашей подпиской и голосовым режимом; без API и без встраивания; подсказка, как вернуться; при возвращении маршрут и музыка на месте |
| **ИИ-помощник** | гибридный: простые команды (маршрут, остановка, поиск места, радио, тема, разделы, напоминания, коды OBD, срок ТО) — на устройстве бесплатно; сложные вопросы — OpenAI или Grok через ваш сервер-прокси (ключи только на сервере) с контекстом поездки (положение, маршрут, музыка, автомобиль, сервис) и вызовом функций приложения; лимиты запросов и бюджета; русский и украинский ([подробнее](docs/AI.md)) |
| **Голос** | русский, украинский, английский; выбор голоса; режим разговора; отдельное отключение ответов, навигационных подсказок и советов |
| **Мой автомобиль** | база знаний Peugeot 3008 со статусом достоверности, подтверждение фактов владельцем, свои заметки |
| **Поездка** | скорость, пробег, время в пути, средняя/максимальная скорость (GPS устройства), следующее ТО, совет дня |

## Голосовые команды

Кнопка микрофона в центре. Без сети и без облачного ИИ работают: «Маршрут до …», «Їдемо до …», «Поехали»,
«Найди заправку», «Заедем на заправку», «Додай зупинку …», «Найди …», «Напомни …», «Включи радио», «Пауза», «Следующая», «Открой настройки», «Выключи голос».
Остальное — вопрос помощнику. Команды для климата, дверей, окон честно отклоняются.

## ChatGPT без API

Кнопка **ChatGPT** открывает `https://chatgpt.com/` в новом окне. На iPad/iPhone с установленным приложением ChatGPT
iOS открывает приложение — работают ваша подписка и голосовой режим, расходов на API нет. Сайт ChatGPT не встраивается
(iframe не используется). Необязательно: быстрая команда iOS для голосового режима — Настройки → ChatGPT по подписке.

## OpenAI и Grok

Ключи OpenAI и xAI **никогда** не хранятся в приложении или репозитории. Они лежат в секретах сервера-прокси
(`server/ai-proxy`, Cloudflare Worker). Подписки ChatGPT Plus и Grok не дают доступа к API — нужен ключ из
platform.openai.com или console.x.ai. Расходы ограничены на трёх уровнях: лимит у провайдера, лимит сервера,
лимит и бюджет в приложении.

## Разработка

```bash
npm install
npm run dev        # dev-сервер
npm test           # unit-тесты (vitest)
npm run build      # проверка типов + сборка в dist/
node scripts/smoke.mjs http://localhost:4173/ smoke --mock   # браузерный тест (после npm run preview)
```

CI (`.github/workflows/ci.yml`): unit-тесты, сборка, браузерный тест на iPad, iPhone и Android с проверкой
наложений элементов. Каждый push в `main` публикуется на GitHub Pages и проверяется на живом сайте с реальными
сервисами (`deploy.yml`).

## Данные и приватность

Профиль, журнал обслуживания, база знаний и избранное хранятся только на устройстве (localStorage).
Наружу уходят: запросы тайлов карты OpenStreetMap (tile.openstreetmap.org, с атрибуцией по правилам OSM), маршрутов (координаты начала и цели — серверам OSRM), поиска мест и адресов точек (Nominatim, Photon) и радио (без других персональных данных) и — если подключён —
запросы к вашему ИИ-прокси (текст вопроса и контекст поездки; координаты — округлённо, можно отключить).
