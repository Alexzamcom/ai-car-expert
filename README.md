# AI Car Expert

Центральный дисплей автомобиля на базе **iPad Pro 12,9″**, установленного **вертикально**.
Адаптивное PWA для iPadOS: тёмная автомобильная тема, крупные элементы управления,
голосовые команды, полноэкранный режим. Основная ориентация — портретная, горизонтальная поддерживается.

## Разделы

| Раздел | Что умеет сейчас |
| --- | --- |
| **Автомобиль** | Профиль авто, пробег, следующее ТО, последнее обслуживание, скорость по GPS. Плитки систем (климат, замки, двери, окна, свет, багажник) явно помечены «Нет интеграции» и ничем не управляют. |
| **AI-помощник** | Чат с голосовым вводом и озвучиванием ответов. Подключается к вашему AI-сервису; без него отвечает из встроенной базы (руководство, коды ошибок, сроки ТО). |
| **Навигация** | Тёмная карта OpenStreetMap/CARTO, геопозиция и скорость по GPS iPad, поиск адресов (Nominatim), избранное и недавние. Пошаговый маршрут — в Apple Картах, Яндекс Навигаторе, Яндекс Картах или Google Maps. |
| **Мультимедиа** | Интернет-радио (можно добавлять свои потоки), воспроизведение аудиофайлов с iPad, Media Session (управление с экрана блокировки и из Пункта управления), ссылки на музыкальные приложения. |
| **Руководство** | Встроенная общая справка: индикаторы на панели, обслуживание, действия в дороге и при ДТП. Поиск, чтение вслух, «Спросить AI». |
| **История обслуживания** | Записи ТО и ремонтов, расходы, расчёт следующего ТО по интервалу, экспорт и импорт JSON. |
| **OBD-диагностика** | Пока заглушка с честным статусом «в разработке» и расшифровщик кодов OBD-II (структура SAE J2012 + справочник распространённых кодов). |

### Раскладка экрана

Экран делится на две панели (в портретной ориентации — верхняя и нижняя, в горизонтальной — левая и правая).
Кнопка в доке открывает раздел в основной панели. Панели можно поменять местами, развернуть на весь экран
или закрыть нижнюю. Раскладка сохраняется между запусками.

### Голосовое управление

Кнопка микрофона в центре дока. Простые команды выполняются сразу, остальное уходит AI-помощнику:

- «Открой навигацию», «Покажи руководство», «Открой историю обслуживания»
- «Маршрут до Красной площади», «Едем в аэропорт»
- «Включи радио», «Пауза», «Следующая»
- «Что значит код P0420?», «Когда следующее ТО?»

Запросы к системам автомобиля («включи кондиционер», «открой багажник») **не выполняются** —
помощник прямо отвечает, что интеграции с автомобилем пока нет.

Распознавание речи использует Web Speech API. Если в режиме веб-приложения на iPadOS оно недоступно,
появляется поле ввода, и можно надиктовать текст через кнопку микрофона на клавиатуре.

## Принципы

- **Никаких имитаций.** Всё, что требует подключения к автомобилю, отображается как недоступное.
  Скорость — по GPS iPad и подписана как таковая. Пробег вводится вручную или берётся из записей ТО.
- **Данные остаются на устройстве.** Всё хранится в `localStorage` этого iPad. Наружу уходят только
  запросы к картам и поиску адресов, потоки радио и запросы к AI-сервису, который вы указали сами.
- **Работа без сети.** Service worker кэширует приложение; часть просмотренных тайлов карты тоже
  доступна офлайн.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev        # dev-сервер (доступен в локальной сети: --host)
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # просмотр собранной версии
```

Сборка статическая (`dist/`) и использует относительные пути, поэтому её можно разместить
на любом HTTPS-хостинге, в том числе в подкаталоге. HTTPS обязателен для геолокации,
микрофона и service worker.

### Установка на iPad

1. Откройте адрес приложения в Safari.
2. «Поделиться» → «На экран „Домой“».
3. Запускайте с экрана «Домой»: приложение откроется без интерфейса Safari.
4. Для постоянной установки в автомобиле: Настройки → Экран и яркость → Автоблокировка → «Никогда».
   Можно включить «Гид-доступ», чтобы закрепить приложение на экране.

## Подключение AI-сервиса

В **Настройках → AI-помощник** укажите адрес своего сервиса (например, прокси к Claude API).
Ключ провайдера должен храниться на сервере, а не в приложении. Необязательный токен отправляется
в заголовке `Authorization: Bearer <токен>`.

Запрос — `POST` с JSON:

```json
{
  "messages": [
    { "role": "user", "content": "Что значит код P0420?" }
  ],
  "context": {
    "vehicle": { "name": "Toyota Camry · 2019", "vin": null, "fuel": "petrol", "odometerKm": 84500 },
    "recentService": [{ "date": "2026-05-10", "odometerKm": 80000, "type": "Плановое ТО", "title": "Плановое ТО" }],
    "vehicleIntegration": false,
    "locale": "ru-RU"
  }
}
```

Ответ — JSON вида `{ "reply": "..." }` (также принимаются поля `text`, `content`, `message`)
или обычный текст. Если сервис недоступен, помощник отвечает из встроенной базы и сообщает об этом.

## Структура

```
src/
  App.tsx              оболочка: статус-бар, две панели, док
  components/          StatusBar, Dock, Pane, VoiceOverlay, Toasts, Icon, CarIllustration
  sections/            Vehicle, Navigation, Media, Assistant, Manual, Service, Diagnostics, Settings
  lib/                 состояние, голос, AI, плеер, навигация, руководство, коды OBD
  styles/global.css    тема и адаптивная раскладка
pwa/sw-template.js     шаблон service worker (список файлов подставляется при сборке)
public/                манифест и иконки
scripts/gen-icons.mjs  генерация PNG-иконок из SVG (Playwright)
```

## Дальше

  поэтому понадобится нативная обёртка или локальный мост.
- Серверный AI-прокси с контекстом руководства конкретной модели.
- Реальная интеграция с автомобилем. Только после неё плитки систем станут активными.
