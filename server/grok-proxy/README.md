# Grok-прокси для AI Car Expert

Небольшой Cloudflare Worker между приложением и xAI API. Ключ xAI хранится только здесь.

## Подписка Grok и API — это разные вещи

Подписка SuperGrok / X Premium даёт доступ к Grok в приложениях X и grok.com, **но не к API**.
API оплачивается отдельно: https://console.x.ai → создать команду → пополнить баланс → API Keys.
Использовать подписку вместо ключа API (через cookies, неофициальные клиенты) нельзя — это нарушает
условия сервиса и ненадёжно.

## Развёртывание (5 минут, бесплатный тариф Cloudflare)

```bash
cd server/grok-proxy
npx wrangler login
npx wrangler secret put XAI_API_KEY      # вставить ключ xAI
npx wrangler secret put ACCESS_TOKEN     # придумать длинную случайную строку, например: openssl rand -hex 24
npx wrangler deploy
```

Wrangler выведет адрес вида `https://ai-car-expert-grok.<аккаунт>.workers.dev`.
В приложении: **Настройки → Помощник Grok** → адрес `https://…workers.dev/chat`, токен — `ACCESS_TOKEN` → «Проверить связь».

## Настройки (`wrangler.toml`)

| Переменная | Назначение |
| --- | --- |
| `ALLOWED_ORIGINS` | откуда разрешены запросы (по умолчанию GitHub Pages приложения) |
| `GROK_MODEL` | идентификатор модели; актуальный список — console.x.ai → Models |
| `MAX_TOKENS` | длина ответа (короткие ответы удобнее в машине) |
| `RATE_LIMIT_PER_MIN` | ограничение запросов в минуту с одного IP |

## Защита

- запросы только с разрешённых Origin и с токеном приложения (сравнение за постоянное время);
- проверка и очистка тела запроса, ограничение размера и количества сообщений/инструментов;
- модель и лимит токенов задаёт сервер, а не клиент;
- ошибки xAI не пересылаются клиенту дословно; ключ не попадает в ответы (проверено тестами).

Тесты: `npm test` в корне репозитория (`tests/unit/grok-proxy.test.ts`).
