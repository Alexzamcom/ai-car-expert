# ИИ-прокси AI Car Expert (OpenAI и Grok)

Cloudflare Worker между приложением и API провайдера. Ключи OpenAI и xAI хранятся **только в секретах Cloudflare**:
не в приложении, не в браузере, не в GitHub и не в логах. Это отдельный сервис Cloudflare, не VPS, не Yenota и не TVoy Hub.
Бесплатного тарифа Workers и KV достаточно.

## Что делает владелец (только в интерфейсах, без терминала)

1. **OpenAI: расходы — с вашего подтверждения.** platform.openai.com → Settings → Billing:
   - пополните баланс на **$5** (предоплата) и **выключите автопополнение** (Auto recharge) — это жёсткий потолок:
     больше баланса OpenAI не спишет;
   - Settings → Limits: задайте месячный бюджет проекта и уведомление (например, $5 и $4).
2. **OpenAI: ключ.** Projects → создайте проект «AI Car Expert» → API keys → *Create new secret key*
   (Permissions: *Restricted*, разрешить только **Model capabilities → Write** и **Models → Read**). Ключ никуда не отправляйте —
   он понадобится в шаге 5.
3. **Cloudflare: аккаунт.** dash.cloudflare.com (бесплатно) → Workers & Pages → при первом входе выберите
   поддомен `*.workers.dev`.
4. **Cloudflare: токен для развёртывания.** My Profile → API Tokens → *Create Token* → шаблон **Edit Cloudflare Workers**
   → Account Resources: ваш аккаунт; Zone Resources: *All zones* (зон у вас может не быть — это нормально) → Create.
   Токен вводится **в защищённую форму сессии Claude Code** (не в чат). С ним Claude создаёт хранилище лимитов (KV)
   и разворачивает Worker `ai-car-expert-ai`.
5. **Cloudflare: секреты** (после развёртывания). Workers & Pages → `ai-car-expert-ai` → Settings → Variables and Secrets →
   *Add* → Type **Secret**:
   - `OPENAI_API_KEY` — ключ из шага 2;
   - `ACCESS_TOKEN` — длинная случайная строка (например, сгенерированный пароль из приложения «Пароли» на iPhone,
     30+ символов). Это пароль приложения к вашему серверу, не ключ OpenAI.
   - (необязательно) `XAI_API_KEY` — ключ console.x.ai, чтобы в приложении работал Grok.
6. **Приложение:** Настройки → «ИИ-помощник» → адрес `https://ai-car-expert-ai.<поддомен>.workers.dev/chat`,
   токен — `ACCESS_TOKEN` → «Сохранить» → «Проверить связь». В той же карточке — расход по данным сервера.
7. **Проверка Claude:** чтобы Claude проверил настоящий диалог, `ACCESS_TOKEN` вводится в защищённую форму сессии для адреса
   сервера. Проверка — около 15 запросов, порядка $0.03.

## Ограничение расходов

| Уровень | Что ограничивает | Надёжность |
| --- | --- | --- |
| Предоплата OpenAI без автопополнения | всё, что может списать OpenAI | **жёсткий потолок** |
| Бюджет проекта OpenAI | уведомления и лимит проекта | у провайдера |
| Сервер: `MONTHLY_BUDGET_USD = 4.5` | деньги за месяц по `usage` из ответов и ценам моделей | KV, общий для всех устройств; оценка по прейскуранту |
| Сервер: `DAILY_REQUEST_LIMIT = 150`, `RATE_LIMIT_PER_MIN = 20`, `MAX_TOKENS = 600` | частота и длина | KV / экземпляр |
| Сервер: `REQUIRE_KV = 1` (при развёртывании) | без хранилища лимитов запросы к OpenAI не выполняются | fail-closed |
| Приложение: лимит в сутки, бюджет, режим «Только на устройстве» | одно устройство | подсказка, **не защита** |

Средний запрос — около 5 тыс. входных токенов (промпт, контекст поездки, база знаний, описания инструментов) и
100–300 выходных. С gpt-5-mini это ≈ $0.0015–0.003 за обращение, команда с вызовом функции — два обращения.
Простые команды не тратят ничего: они выполняются на устройстве.

## Модель

`OPENAI_MODEL` — список экономичных моделей с вызовом функций по порядку предпочтения
(`gpt-5-mini,gpt-5.4-mini,gpt-4.1-mini`). Сервер один раз в час берёт список моделей, доступных ключу, и использует
первую подходящую. Если OpenAI отвечает, что модель недоступна, сервер пробует следующую. Если модель не принимает
`reasoning_effort`, запрос повторяется без этого параметра. Какая модель ответила — видно в «Проверить связь» и в отчёте проверки.
Цены моделей для бюджета — в `src/handler.js` (`PRICES`), неизвестная модель считается по завышенной цене;
переопределяются переменными `OPENAI_PRICE_IN` / `OPENAI_PRICE_OUT`.

## Адреса сервера

| Запрос | Доступ | Что возвращает |
| --- | --- | --- |
| `GET /health` | открыто | настроены ли провайдеры (без ключей), модели, лимиты |
| `GET /usage` | токен приложения | расход за месяц, бюджет, запросы сегодня |
| `POST /chat` | токен приложения + разрешённый Origin | ответ модели, `usage`, провайдер |

## Защита

- Ключи провайдеров — только секреты Worker; в ответы и сообщения об ошибках не попадают (тесты).
- Запросы только с разрешённых Origin и с токеном приложения (сравнение за постоянное время).
  Утёк токен — смените `ACCESS_TOKEN` в Cloudflare; ключ OpenAI менять не нужно.
- Модель, длину ответа и лимиты задаёт сервер. Тело запроса проверяется: роли, размеры, имена инструментов.

## Для разработчика

- `node scripts/ai-proxy-config.mjs` — находит или создаёт KV `ai-car-expert-usage` и пишет `wrangler.ci.toml`
  (KV + `REQUIRE_KV=1`); затем `npx wrangler@4.152.0 deploy --config wrangler.ci.toml`.
- `node scripts/ai-live-check.mjs <адрес>/chat` — сквозная проверка с настоящим сервером (голос имитируется);
  `--fake-ai` — без расходов, с имитацией сервера.
- Тесты: `npm test` (`tests/unit/ai-proxy.test.ts`).
