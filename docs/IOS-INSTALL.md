# AI Car Expert на iPhone и iPad

Приложение использует общий интерфейс AI Car Expert в Capacitor. Минимальная версия системы — iOS / iPadOS 17. Bundle ID проекта — `com.aicarexpert.app`. В GitHub Actions рабочий процесс **iOS IPA and simulator** собирает arm64 IPA без Apple-подписи и отдельно проверяет приложение на симуляторе. GitHub не получает Apple ID, пароль, код двухфакторной авторизации или профиль мобильной подписи.

## Первая установка

1. Откройте последний успешный запуск **iOS IPA and simulator** и скачайте артефакт **ai-car-expert-ios-unsigned-ipa**. Распакуйте ZIP, внутри находится `AI-Car-Expert-iOS-unsigned.ipa`.
2. Установите [Sideloadly](https://sideloadly.io/) на ASUS, если на нём Windows 10/11. Для подключения Windows установите компоненты Apple, указанные в инструкции Sideloadly. MacBook Air 2013 года подходит только если версии macOS, Sideloadly и Apple Mobile Device признают модель телефона и установленную iOS. Компилировать приложение на этом MacBook не требуется.
3. Подключите iPhone кабелем, разблокируйте его и подтвердите доверие к своему компьютеру. Откройте IPA в Sideloadly, выберите устройство и войдите в свой Apple ID только в приложении Sideloadly. Для iPad повторите выбор устройства с тем же аккаунтом.
4. Используйте один и тот же итоговый Bundle ID во всех последующих установках. Если Sideloadly изменит исходный идентификатор для Personal Team, запишите итоговое значение и сохраняйте его при обновлении. Сохраняйте тот же Apple ID и Personal Team. Данные WebView и офлайн-карты привязаны к контейнеру приложения.
5. При необходимости включите **Настройки → Конфиденциальность и безопасность → Режим разработчика**, перезапустите устройство и подтвердите включение. Если iOS запросит доверие к разработчику, подтвердите его в **Настройки → Основные → VPN и управление устройством**. Откройте AI Car Expert и разрешите геолокацию при использовании приложения.

## Повторная подпись и обновления

Бесплатная подпись Personal Team имеет короткий срок, обычно 7 дней. Apple также ограничивает количество зарегистрированных App ID и тестовых устройств. При достижении лимита Sideloadly покажет ошибку provisioning. Проверяйте срок профиля и повторно подписывайте IPA до истечения срока. Допускается функция автоматического обновления подписи Sideloadly, когда для неё доступны компьютер и подключённое устройство.

Для новой версии подпишите актуальный IPA тем же аккаунтом и с тем же итоговым Bundle ID, затем установите его поверх установленного приложения. Не удаляйте приложение для продления подписи. Удаление приложения, смена подписывающей команды или изменение итогового Bundle ID могут лишить доступа к прежним данным. Пользовательские данные можно сохранить только при совместимом обновлении. Сохранённые места можно отдельно экспортировать из приложения.

Источники: [Sideloadly](https://sideloadly.io/), [сравнение бесплатного аккаунта и Developer Program](https://developer.apple.com/support/compare-memberships/), [Developer Mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device).

## Офлайн-режим и проверка

- Загружайте пакеты в **Настройки навигации и HUD → Офлайн-карты**. После скачивания проведите первый тест в Павлограде с выключенной сетью. Выберите ручной старт, задайте адрес назначения и повторите расчёт после перезапуска.
- Файлы графа, тайлы, шрифты и индекс адресов на iOS хранятся в `Library/Application Support/OfflineMaps`, а не в кэше WebView. Каталог пакетов сохраняется атомарно. Пакеты исключены из облачной резервной копии, поскольку скачиваются повторно. Настройки и сохранённые места используют постоянное хранилище WKWebView с неизменным origin.
- Локальный Valhalla работает в отдельном Worker. iOS получает WASM из бандла приложения и передаёт файлы графа по одному из нативного хранилища. При сбое Worker приложение ограничивает ожидание и повторяет запуск один раз.
- Для камеры на iOS действует обычный профиль графики с адаптацией к доступным ресурсам. Android-ограничение облегчённого стиля не применяется автоматически. Плавность, расход памяти, аккумулятора и нагрев требуется измерить на физическом iPhone, желательно на длительном маршруте с переключением ориентации, классического и игрового HUD.
- Без надёжных измерений расстояния оценка движения ограничена. Симулятор проверяет запуск, локальное хранилище и маршрут, но не подтверждает реальную точность Core Motion, GNSS, зеркальную проекцию или голос в автомобиле. Приложение работает на переднем плане. CarPlay, фоновая навигация и App Store в эту поставку не входят.
