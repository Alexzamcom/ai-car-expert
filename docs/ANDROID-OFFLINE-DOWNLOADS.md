# Загрузка автономных карт Android

Телефон запрашивает встроенный каталог данных и по явному поиску получает населённые пункты без привязки к GPS. Один объект OSM (тип N/W/R и ID) связывает имя, область, страну, центр предпросмотра и пакет. Если ID, радиус или центр в манифесте расходятся с выбранным населённым пунктом, пакет отклоняется. Для Павлограда каталог индексирует «Павлоград», Pavlohrad и Pavlograd. Одноимённые и похожие населённые пункты показаны отдельно со страной.

Данные собирает workflow из официального экстракта [Geofabrik](https://download.geofabrik.de/europe/ukraine.html). Один OSM-экстракт используется для адресов, векторных тайлов [Tilemaker](https://github.com/systemed/tilemaker) и графа [Valhalla](https://valhalla.github.io/valhalla/). Карта содержит дороги, подписи и геометрию зданий. Граф учитывает направления проезда и поддерживаемые Valhalla ограничения из OSM. Файл Украины занимает сотни мегабайт до выделения города; построение связного графа и векторных тайлов требует нативных инструментов, значительной памяти и диска. Телефон скачивает только выбранный уже подготовленный регион.

Автоматическая сборка проверяет контрольные суммы, реальные адреса и локальный автомобильный маршрут до отправки данных в ветку `offline-map-data`. Это ветка статических данных, отдельная от сайта и APK. Начальный набор для проверки — Павлоград и Дніпро, радиус 25 км. Сборщик принимает произвольный список городов и радиусы 10, 25, 50 и 100 км. Расширение публичного каталога зависит от подготовки соответствующих данных. Интерактивная сборка любого населённого пункта по запросу телефона пока отсутствует.

Клиент проверяет SHA-256 каждой части и её ресурсов, после чего сохраняет данные и прогресс в одной транзакции IndexedDB. После обрыва продолжение начинается со следующей части. Размер показывается до загрузки. Проверка свободного места использует меньшую из доступных оценок Android и WebView. Обновлённая карта заменяет старую только после успешной проверки. Локальные поиск и маршрут внутри покрытия используют сохранённые данные. При неподтверждённом движении алгоритм ведения по-прежнему показывает неопределённость.

OSM-данные распространяются с атрибуцией по [ODbL 1.0](https://www.openstreetmap.org/copyright). Шрифты Noto Sans предоставляются через [Protomaps Basemaps Assets](https://github.com/protomaps/basemaps-assets) по SIL OFL 1.1. Граф, индекс и векторные данные доступны вместе с указанием исходного экстракта. Массовая загрузка публичных растровых или векторных тайлов для формирования пакетов не используется.
