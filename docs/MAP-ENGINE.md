# Движок карты: Leaflet сейчас, MapLibre GL — прототип

## Что нужно автомобильной навигации

Карта по направлению движения (поворот), наклон 3D, плавная камера, поворот двумя пальцами, векторная карта
со своим оформлением днём и ночью, бесплатные данные без ключей.

## Сравнение

| | Leaflet 1.9 (рабочая навигация) | MapLibre GL JS 6.16 (прототип `lab.html`) |
| --- | --- | --- |
| Поворот карты | нет; плагин leaflet-rotate — **GPL-3.0** (см. ниже) | встроен; поворот двумя пальцами |
| Наклон 3D | нет (тот же плагин) | встроен (`pitch`) |
| Тайлы | растровые OSM (`tile.openstreetmap.org`), оформление только CSS-фильтром | векторные OpenFreeMap (бесплатно, без ключа), палитра день/ночь задаётся стилем |
| Размер | ~40 КБ | ~1,1 МБ + воркер 0,5 МБ (грузится только в прототипе, не в кэше приложения) |
| Нагрузка | DOM, лёгкая | WebGL: на GPU плавно, без GPU — тяжело |
| Лицензия | BSD-2 | BSD-3 |

**leaflet-rotate** (поворот и наклон для Leaflet) распространяется под **GPL-3.0**. У проекта нет открытой лицензии;
включение GPL-кода в сборку распространяет на приложение требования GPL. Это решение владельца, поэтому плагин не подключён.

## Что сделано сейчас (без замены рабочей карты)

- Курс машинки: `updateHeading` — общий для обоих движков (`src/lib/nav.ts`, тесты `tests/unit/gps.test.ts`).
- Leaflet: камера с упреждением (машинка позади центра по ходу движения), плавное линейное следование, масштаб по
  скорости, свободный обзор при сдвиге карты, «К машине» — возврат; приглушённая дневная карта, широкий маршрут.
- Прототип MapLibre (`lab.html`, Настройки → «Машинка на карте» → «Карта 3D»):
  - режимы «По движению» (наклон 50°, машинка в нижней трети, карта по курсу) и «Север сверху»;
  - жест (сдвиг, поворот двумя пальцами, наклон) → «Свободный обзор», кнопка «Следовать» возвращает режим;
  - машинка с `rotationAlignment: 'map'` — поворот по курсу относительно севера, без двойного вращения с картой;
  - плавное движение машинки между точками GPS и линейная камера `easeTo` (1 с);
  - ночная палитра векторной карты, маршрут из приложения (`ace:nav-session`), голосовые подсказки и кнопка динамика;
  - `?sim=1` — демонстрационная поездка (центр Киева), `?hud=1` — кадры в секунду.
- Замер: `scripts/map-bench.mjs` (Leaflet и MapLibre, iPad / iPhone / Android, замедление процессора), запускается в
  `deploy.yml` на опубликованном сайте с настоящими тайлами. В CI WebGL рисуется программно (без GPU) — числа MapLibre
  там занижены; окончательное сравнение — на устройствах.

## 3D-машинка

Собственная процедурная модель (`src/lib/car3d/mesh.ts`, без сторонних файлов и лицензий): кроссовер ~4,6 × 1,9 × 1,7 м,
372 треугольника — кузов с фасками капота и багажника, кабина со стёклами (лобовое наклонено сильнее), крыша и
рейлинги, стойки, бамперы и пороги, светящиеся фары и задние фонари, колёса с дисками.

Отрисовка — пользовательский WebGL-слой MapLibre (`src/lib/car3d/layer.ts`), один проход без библиотек:
- размер постоянный на экране (50–76 px в зависимости от устройства), как в навигаторах;
- курс от севера по часовой; поворот и наклон карты учитывает матрица MapLibre — без двойного вращения;
- освещение в координатах модели (свет сзади-сверху), затенение у порогов, блик на кузове и стёклах, мягкая тень;
- цвет кузова — из настроек (тот же выбор 12 цветов), плавный поворот — общий с плоской машинкой;
- на стоянке не вращается: курс уже отфильтрован (`updateHeading`);
- «Плоская» в настройках — облегчённый вариант; при ошибке WebGL — автоматически плоская.

Добавить модель: функция построения в `CAR_MODELS` (`mesh.ts`), например седан или пикап.

## Основная навигация на MapLibre (этап 2)

Настройки → «Машинка на карте» → «Движок карты»: **MapLibre 3D** или **Leaflet** (резерв). Переключение в любой момент,
в том числе во время ведения, не сбрасывает маршрут: GPS, фильтр точек, маршрут и варианты, остановки, перестроение,
поиск, долгое нажатие, полноэкранный режим, голос и восстановление после переключения приложений — общие.
`src/sections/MapLibreMap.tsx` только рисует (маршрут, варианты, цель, остановка, выбранная точка, объекты по пути,
круг точности, 3D-машинка) и ведёт камеру; MapLibre загружается лишь при выборе этого движка.

- По движению: карта по курсу, наклон 50°, машинка в нижней четверти; Север сверху — упреждение по ходу движения.
  Переключатель «Курс / С» — рядом с динамиком при ведении и в настройках.
- Сдвиг, поворот двумя пальцами, наклон — свободный обзор; «К машине» возвращает выбранный режим.
- Автомасштаб (`autoZoom`): по скорости, перед манёвром плавно приближает перекрёсток (от 500 до 120 м), без скачков;
  щипок пользователя действует до «К машине».
- Палитры (`src/lib/mapStyle.ts`): день, ночь, HUD; цвета маршрута — из темы приложения.
- Просмотренные векторные тайлы кэшируются (до 800) на случай коротких пропаданий связи.

## Условия замены рабочей карты на MapLibre

Прототип становится рабочим движком только после проверки на iPad Pro 12.9″ (и iPhone, Android):

1. Плавность ≥ 50 к/с в режиме «По движению» с наклоном, без перегрева за 30 минут поездки.
2. GPS: машинка на месте, курс по дороге, поведение на стоянке, задний ход, тоннели.
3. Маршрут, варианты, остановки, перестроение, поиск, долгое нажатие для выбора точки.
4. Жесты: сдвиг, щипок, поворот, наклон — без конфликтов с панелью ведения.
5. Возврат из YouTube Music / ChatGPT и после выгрузки приложения iPadOS.
6. Работа без сети: кэш векторных тайлов (сейчас не реализован).

## Риски

- OpenFreeMap — бесплатный публичный сервис без гарантий; для массового использования — свой сервер тайлов
  (PMTiles на CDN) или другой провайдер (платные — только с согласия владельца).
- Размер и энергопотребление WebGL на iPad в машине (нагрев, зарядка).
