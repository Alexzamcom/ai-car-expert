# Управление воспроизведением YouTube Music из AI Car Expert

Задача: из автомобильного интерфейса (веб-приложение на экране «Домой» iPad) переключать треки,
ставить на паузу и возобновлять YouTube Music, который играет в своём приложении.

## Вывод

**Прямого законного способа нет.** Веб-приложение на iPadOS не может отправлять команды воспроизведения
другому приложению. Поэтому в интерфейсе нет кнопок «назад / пауза / вперёд» для YouTube Music — они
были бы фиктивными. Вместо них — подсказка о трёх системных способах, которые управляют YouTube Music
без перехода в него, и честные ответы голосовых команд.

## Подтверждено (спецификации, документация платформы, наблюдения на устройстве)

| Механизм | Что умеет | Почему не подходит для команд YouTube Music |
| --- | --- | --- |
| **Media Session API** (Safari, PWA) | Страница **принимает** команды «пауза/вперёд/назад» для **своего** звука (экран блокировки, Пункт управления, кнопки на руле) и показывает название трека | Только для звука самой страницы. Отправить команду чужому приложению нельзя — API в эту сторону не работает. AI Car Expert уже использует его для встроенного радио. |
| **Системный медиаплеер iOS** (MPRemoteCommandCenter, MPNowPlayingInfoCenter, MPMusicPlayerController) | Нативные API: свой «Сейчас играет»; MPMusicPlayerController управляет только Apple Music | Недоступны веб-страницам. Даже нативное приложение не может управлять воспроизведением другого стороннего приложения (YouTube Music) — только своим звуком или Apple Music. |
| **Bluetooth AVRCP** | Магнитола (контроллер) отправляет iPad (цели) «пауза/вперёд/назад»; iOS передаёт их приложению, которое сейчас владеет «Сейчас играет» | Направление — от машины к iPad. Веб-приложение не может стать контроллером: Web Bluetooth в Safari нет, а AVRCP-контроллер требует системного уровня. |
| **URL-схема `youtubemusic://`** | Открывает приложение (работает на вашем iPad) | Официально документированных ссылок для «пауза/следующий трек» нет. |
| **Встраивание (iframe, IFrame Player API)** | Управление видеоплеером YouTube внутри страницы | Запрещено задачей; это был бы другой плеер, не ваше приложение YouTube Music, и без фонового воспроизведения на iOS. |
| **Неофициальные API YouTube Music, приватные API iOS, jailbreak** | — | Запрещены задачей и правилами сервисов. |

## Работающие способы управлять YouTube Music, не покидая AI Car Expert

Все три — средства iPadOS; они управляют приложением, которое сейчас играет («Сейчас играет»).

1. **Пункт управления** — смахнуть вниз от правого верхнего угла экрана iPad. Плеер «Сейчас играет»:
   назад, пауза/воспроизведение, вперёд. Открывается поверх любого приложения, включая AI Car Expert.
   *Подтверждено поведением iPadOS для любого приложения, владеющего «Сейчас играет».*
2. **Кнопки на руле или магнитоле** — если iPad подключён к автомобилю по Bluetooth как аудиоустройство,
   команды AVRCP получает приложение «Сейчас играет». *Подтверждено для iPadOS; для конкретной магнитолы
   Peugeot 3008 2010 — гипотеза (см. ниже).*
3. **Siri** — «Привет, Siri, пауза», «…следующий трек», «…предыдущий трек», «…продолжи».
   *Системные команды Siri для «Сейчас играет»; для YouTube Music — проверить на устройстве.*

## Android

Аналогично: веб-страница не может управлять другим приложением. Системные способы — плеер YouTube Music
в шторке уведомлений, Google Ассистент («Окей, Google, пауза / следующий трек»), кнопки на руле (AVRCP).
Интерфейс показывает подсказки для Android, а не для iPad.

## Гипотезы — проверить на iPad

- **Siri и YouTube Music.** Ожидается, что «пауза / следующий трек» работают для YouTube Music как для
  «Сейчас играет». Проверить на русском языке Siri.
- **Магнитола Peugeot 3008 (2010).** Поддержка потокового звука по Bluetooth (A2DP) и кнопок (AVRCP) зависит
  от установленного головного устройства. Проверить: играет ли музыка iPad через динамики машины по
  Bluetooth и переключают ли треки кнопки на руле.
- **Быстрые команды («Команды»).** В приложении есть действия «Воспроизвести/пауза», «Перейти к следующему»,
  «Перейти к предыдущему». Ожидается, что они управляют «Сейчас играет». Но запуск команды из веб-приложения
  по ссылке `shortcuts://run-shortcut?name=…` выводит на экран приложение «Команды», и оно остаётся открытым:
  каждое нажатие уводило бы из AI Car Expert. Поэтому такие кнопки в интерфейс не добавлены. Команды удобны
  как отдельные кнопки на экране «Домой» или для Siri — но и там они временно открывают «Команды».
- **Фоновое воспроизведение YouTube Music** при возврате в AI Car Expert зависит от подписки YouTube Premium.

## Что сделано в приложении

- В разделе «Музыка → YouTube Music» — блок «Управление в машине» с тремя способами выше. Это подсказка,
  а не кнопки, которые делают вид, что управляют.
- Голосовые команды AI Car Expert «пауза», «следующая», «играй», пока активен YouTube Music, больше **не
  трогают** встроенное радио (раньше «играй» могло включить радио поверх YouTube Music) и отвечают, как
  выполнить действие через Siri или Пункт управления.
- Встроенное интернет-радио по-прежнему управляется кнопками приложения, кнопками на руле и с экрана
  блокировки (Media Session API).
