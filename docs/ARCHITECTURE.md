# Архитектура

```
iPad / iPhone / Android (PWA, React + TypeScript + Vite)
 ├─ Главный экран: карта (Leaflet) + панель (Музыка / Grok / Приложения / Поездка)
 ├─ Разделы поверх: Мой автомобиль, Справочник, Сервис, OBD, Настройки
 ├─ Голос: Web Speech API (ru-RU, uk-UA, en-US) → быстрые команды → инструменты
 ├─ Данные владельца: localStorage (профиль, журнал ТО, база знаний, избранное)
 └─ Внешние сервисы (без ключей): OSRM, Nominatim, Overpass, Radio Browser, CARTO
            │
            ▼  HTTPS + токен доступа приложения
Grok-прокси (Cloudflare Worker, server/grok-proxy) ── ключ xAI в секрете ──▶ api.x.ai
```

## Помощник и инструменты

`src/lib/tools.ts` — единый набор действий. Их вызывает Grok (function calling) и быстрые голосовые
команды без сети (`src/lib/voiceCommands.ts`). Помощник не получает инструментов управления автомобилем.

## Достоверность знаний

Каждый факт базы (`src/lib/knowledge`) имеет статус: `owner`, `documented`, `typical`, `community`.
Системный промпт требует от Grok сообщать о неподтверждённых данных; офлайн-ответы добавляют пометку сами.

## Интеграция с автомобилем: границы и разрешения

`src/lib/vehicle/types.ts` — модель модулей и разрешений:

| Разрешение | Что даёт | ИИ может инициировать |
| --- | --- | --- |
| `read` | чтение данных (OBD PID, коды ошибок, статус охраны) | да, если владелец разрешил |
| `notify` | события от модуля (тревога, низкое напряжение) | только показывать |
| `command` | команды автомобилю | **никогда**; не реализуется без отдельной проверки безопасности, и даже после — только явным действием водителя |

### OBD-II (план)

- Safari на iPad не поддерживает Web Bluetooth и Web Serial — Bluetooth-адаптер из PWA недоступен.
- Вариант 1: Wi-Fi ELM327 + маленький локальный мост (Raspberry Pi/ESP32 в машине), отдающий
  данные по HTTPS/WebSocket в локальной сети. Мост реализует только чтение: Mode 01 (параметры),
  03/07 (коды), 09 (VIN). Mode 04 (сброс кодов) — только по явной кнопке владельца.
- Вариант 2: нативная обёртка (Capacitor) с Bluetooth LE.
- Запрещено: запись в блоки, кодирование, команды исполнительным механизмам.

### Модуль охраны (отдельный этап)

- Собственное устройство с независимым питанием и связью; приложение — только клиент.
- Обмен: подписанные события (статус, тревога, координаты) по TLS; приложение хранит только последний статус.
- Дистанционные команды (запуск, открытие) не планируются. Любое расширение — после анализа угроз.

## Секреты

- Ключ xAI — только `wrangler secret` на сервере. В репозитории и в клиентском JavaScript ключей нет.
- Токен доступа к прокси вводит владелец в настройках; хранится в localStorage его устройства.
- CI проверяет, что ключ не попадает в ответ прокси (`tests/unit/grok-proxy.test.ts`).
