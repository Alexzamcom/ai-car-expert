# План развития

Приоритеты: P0 — безопасность и работоспособность в движении, P1 — основная ценность, P2 — развитие.

## Этап 1–2. Автомобильный интерфейс — выполнено в этой версии

- [x] Главный экран «Вождение»: карта — главный элемент, панель с вкладками Музыка / Grok / Приложения / Поездка.
- [x] Панель сворачивается, разворачивается, меняется местами с картой; на телефоне по умолчанию свёрнута.
- [x] Справочник, диагностика, сервис, настройки, «Мой автомобиль» — отдельные разделы поверх карты (маршрут продолжает вестись).
- [x] Элементы карты в сетке без наложений; автотест наложений на iPad/iPhone/Android.
- [x] Маршрут (OSRM), ведение по шагам с голосовыми подсказками ru/uk/en, перестроение при сходе с маршрута.
- [x] АЗС, места отдыха, кафе, парковки по маршруту (Overpass), заезд как промежуточная точка.
- [x] Передача маршрута в Apple Карты, Google Maps, Яндекс Навигатор/Карты, Waze — с явной пометкой.
- [x] Радио: каталог Radio Browser (поиск, RU/UA, жанры), только воспроизводимые HTTPS-потоки, избранное,
      восстановление последней станции.
- [x] Быстрый запуск приложений, бортовой компьютер по GPS.

## Этап 3. Помощник Grok

- [x] Серверный прокси (Cloudflare Worker), ключ только в секрете, токен доступа, CORS, лимит запросов, тесты.
- [x] Function calling: маршрут, АЗС, радио, разделы, приложения, голос, коды ошибок, база знаний.
- [x] Распознавание и синтез речи ru-RU / uk-UA, выбор голоса, режим разговора, раздельное отключение ответов и подсказок навигации.
- [ ] **P0 — требует владельца:** развернуть прокси со своим ключом xAI (инструкция: `server/grok-proxy/README.md`).
- [ ] P1: потоковые ответы (озвучивание по мере генерации) — меньше задержка в машине.
- [ ] P1: серверное распознавание речи (если Web Speech в режиме веб-приложения на iPadOS окажется нестабильным).
- [ ] P2: долговременная память диалогов (сейчас контекст — последние 16 сообщений + профиль + база знаний + журнал ТО).

## Этап 4. Персонализация Peugeot

- [x] Профиль Peugeot 3008 2010 1.6 THP по умолчанию; база фактов со статусами достоверности; подтверждение владельцем; свои заметки.
- [x] Совет дня (можно отключить), помощник сообщает о неподтверждённых данных.
- [ ] **P1 — требует владельца:** VIN, точная версия двигателя (150/156 л. с.), КПП, комплектация; фото табличек и кнопок.
- [ ] P1: фото кнопок и панели в базе знаний (хранение в IndexedDB, распознавание моделью с поддержкой изображений).
- [ ] P1: напоминания по ТО (дата/пробег) с уведомлением на главном экране; журнал кодов ошибок.
- [ ] P2: импорт PDF-руководства владельца → фрагменты в базе знаний со ссылкой на страницу (на сервере).

## Этап 5. Интеграции

- [ ] P1: OBD-II — Wi-Fi ELM327 + локальный мост (см. [ARCHITECTURE](ARCHITECTURE.md)); только чтение (Mode 01, 03, 07, 09).
- [ ] P1: автомобильный режим iPadOS через Команды (см. [CAR-MODE](CAR-MODE.md)) — проверить на устройстве владельца.
- [ ] P2: модуль охраны — только статус и уведомления, без дистанционных команд.
- [ ] P2: нативная обёртка (Capacitor), если понадобятся Bluetooth LE, фоновая работа или CarPlay.

## Требует проверки на реальном устройстве

- Вывод синтеза речи и радио через Bluetooth автомобиля; поведение при входящем звонке.
- Web Speech API в режиме веб-приложения «На экране Домой» на iPadOS (ru и uk).
- Удержание экрана (Wake Lock) в автомобиле, нагрев iPad при постоянной навигации.
