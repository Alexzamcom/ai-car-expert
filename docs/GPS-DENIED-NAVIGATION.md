# AI Car Expert · экспериментальная навигация без GPS

Прототип для закрытой площадки и анализа записей. Экран показывает оценку, точность которой ещё не проверена на физических телефонах. Строитель маршрута и тайлы используют сеть. Режим работает без GPS после подготовки маршрута, при доступной геометрии маршрута. Полной офлайн-карты и офлайн-маршрутизатора пока нет.

## Реализация A–E

- **A.** Ветка объединяет рабочие снимки PR #43 и #44 для сборки Capacitor и переиспользования MapLibre, машины и камеры. Исходные ветки PR остаются независимыми.
- **B.** Android читает SensorManager и LocationManager, iOS — Core Motion и Core Location. Нативный мост нормализует земную вертикаль и передаёт горизонтальное ускорение в м/с², вертикальную угловую скорость в градусах/с и матрицу ориентации. Положение, направление и маршрут экспериментального режима хранятся в отдельном источнике карты. Нативный флаг удерживает экран включённым до остановки режима. Уход в фон или отсутствие новых отсчётов приостанавливает оценку.
- **C.** После ручной привязки продольная ось калибруется по первому прямому разгону. Интегрируются угловая скорость и ограниченное продольное ускорение. При низкой скорости и малом движении применяется остановка. Коридор выбранного маршрута ограничивает поперечный снос. Для принятия ближайшего угла маршрута нужны обнаруженный поворот, близость и согласованное направление на выходе. Неопределённость растёт по времени, дистанции и поворотам. При высокой неопределённости или уходе с коридора указания скрываются.
- **D.** Гибрид принимает только скорость с малым весом после проверки возраста пары, точности, ускорения, приращения расстояния, курса и согласия с инерцией. Абсолютная координата никогда не становится состоянием машины. Согласованный спуфинг может пройти проверки. Гибрид по умолчанию выключен.
- **E.** Запись включается отдельной отметкой согласия и сохраняется в локальный IndexedDB. Каждое событие хранит время, вход, оценку, статус GPS и оценку неопределённости. Запись содержит версию алгоритма, маршрут, ручные поправки, повороты, остановки и обратную связь. Контрольная точка водителя помечена отдельно. Записи можно удалять и отправлять через системное меню экспорта по явному действию.

Интерфейс `Measurement` содержит независимый источник скорости и расстояния для будущего OBD. В этой версии адаптера OBD нет. Будущие модели можно сравнивать через один формат воспроизведения, заменяя оценку скорости, поворота или доверия. Разбивайте выборку на поездки, телефоны и автомобили. Используйте независимые засечки и проверенную телеметрию, храните происхождение меток. Недостоверный GPS и оценка водителя не являются эталоном.

## Тестирование

### Android

Установите отладочный APK из Actions или выполните `npm ci`, `npm run android:sync`, затем `cd android && ./gradlew assembleDebug`. Нужны JDK 21 и Android SDK 35. Установите APK через `adb install -r app/build/outputs/apk/debug/app-debug.apk` из каталога android. Пакет использует тот же идентификатор, что #43, поэтому для параллельной проверки используйте отдельное устройство или эмулятор.

### iPhone и iPad

На macOS с Xcode и CocoaPods выполните `npm ci`, `npm run ios:sync`, `npx cap open ios`. В Xcode выберите команду подписи и физический iPhone. Артефакт симулятора устанавливается через `xcrun simctl install booted App.app`. Симулятор может не предоставлять Core Motion. При отсутствии датчиков приложение показывает ошибку и оставляет режим подготовки.

### Общий сценарий и проверка записей

1. На стоянке откройте навигацию без активного маршрута и нажмите «GPS показывает неверное местоположение».
2. Совместите центральный прицел с полосой, укажите курс от севера по часовой стрелке и подтвердите. Переместите карту в пункт назначения и дождитесь построения.
3. Закрепите телефон. По согласию включите запись, оставьте GPS выключенным для первого проезда. Начните с остановки и плавно разгонитесь по прямой. Повторите с другим наклоном держателя и с включённой относительной GPS-помощью.
4. На закрытой площадке проверьте разгон, прямую, остановку, поворот, ошибочную ветку маршрута, помеху в виде переориентации телефона и паузу после сворачивания. При необходимости откорректируйте точку и направление после остановки.
5. Завершите поездку, укажите погрешность, отметьте фактический финиш под прицелом. Повторно войдите в экран «Записи поездок», сравните варианты или экспортируйте JSON.
6. В архиве выберите потерю GPS, неподвижную метку, скачок или плавное ложное смещение и нажмите «Сравнить». Без записанных GPS-отсчётов сценарии дают одинаковый вход. Для сравнения с независимыми засечками выполните `npx vite-node scripts/replay-trip.ts trip.json reference.json`. Файл засечек представляет массив `[{ "at": 1700000000000, "position": { "lat": 48.46, "lon": 35.04 } }]` с миллисекундами Unix. Вывод содержит число пар в окне ±250 мс, RMS и отклонение от отметки водителя отдельно.

| Ограничение | Влияние и проверка |
| --- | --- |
| Дрейф скорости при постоянном ходе, торможении и на уклоне | Тесты на форму и синтетическую кинематику не оценивают реальный дрейф. Нужны независимые контрольные точки или одометр на закрытой площадке. |
| Резкий разгон, перестановка телефона, поездка задним ходом | Калибровка предполагает неподвижный держатель и начальное поступательное ускорение. После изменения установки требуется остановка и коррекция. |
| Параллельные дороги, плавные съезды и неверный поворот | Привязка использует только коридор рассчитанного маршрута. Поиск по полной дорожной сети и автоматическое перестроение отсутствуют. |
| Плавный согласованный спуфинг | Может пройти фильтр скорости. Он влияет только косвенно, риск остаточного дрейфа сохраняется. |
| Шум, задержки, отключённые датчики и энергосбережение | Время и направление осей надо проверить на физических iPhone и Android при разных держателях. Эмуляция подтверждает программную обработку. |
| Неопределённость | Значение в метрах эвристическое, без измеренной статистической калибровки. Положение и предупреждения не предназначены для использования как единственный источник на дорогах. |
| Записи | До 100 000 отсчётов, примерно 80 минут при 20 Гц. Последний контрольный снимок записывается каждые 30 с и при завершении. Экспорт может содержать чувствительные координаты. |

## Контролируемый синтетический прогон

22 секунды на прямой: разгон 2 м/с² до 8 м/с, постоянный ход 12 секунд, торможение 2 м/с² и 2 секунды стоянки. Для инерциального входа добавлено смещение 0,12 м/с² по продольной оси. За эталон взяты 23 точки той же аналитической траектории до добавления ошибки. Это проверка сравнения вариантов, без оценки точности на автомобиле.

| Вариант | GPS по траектории | Потеря GPS | Ложная неподвижная точка | Скачок | Плавная ложная позиция |
| --- | ---: | ---: | ---: | ---: | ---: |
| Инерциальный | 9,72 м | 9,72 м | 9,72 м | 9,72 м | 9,72 м |
| Дорожный | 9,72 м | 9,72 м | 9,72 м | 9,72 м | 9,72 м |
| Гибридный | 6,03 м | 9,72 м | 9,72 м | 6,07 м | 7,98 м |

В первом прогоне неподвижная GPS-метка тормозила гибрид при старте и давала RMS 65,14 м. Убрано использование близкой к нулю GPS-скорости как свидетельства остановки. Результат 7,98 м при плавной подмене подтверждает остаточное влияние правдоподобного ложного измерения.
