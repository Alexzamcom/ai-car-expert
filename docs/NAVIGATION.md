# Навигация: устройство, надёжность, ограничения

## Как пользоваться

- **Выбрать точку на карте** — зажать палец на любом месте карты ~0,6 с (на iPad, iPhone, Android)
  или щёлкнуть правой кнопкой мыши на компьютере. Появляются метка и карточка: адрес (или координаты, если
  адреса нет), расстояние по прямой и кнопки **«Маршрут сюда»**, **«Добавить остановку»** (если маршрут уже есть),
  **«Отмена»**.
- **Поиск** — адреса, улицы, дома, города, объекты; можно ввести координаты «50.4501, 30.5234». Результат
  показывается точкой на карте с той же карточкой: маршрут — одним нажатием.
- **Маршрут** — по дорогам, с расстоянием, временем в пути и временем прибытия. Если сервис предложил
  альтернативы, они видны серыми линиями и кнопками «6 мин · 2,4 км»; выбрать — нажатием на кнопку или линию.
- **«Поехали»** — 3 секунды виден весь маршрут, затем камера следует за машиной. Сдвинули карту —
  появляется кнопка **«Вернуться к машине»**. Вверху — ближайший манёвр и расстояние до него, внизу — прибытие,
  время в пути, остаток пути.

Не срабатывает долгое нажатие: при сдвиге карты (палец ушёл дальше 10 px), при жесте двумя пальцами
(масштаб, прокрутка) — до отпускания всех пальцев, при коротком касании, на кнопках, карточках и метках карты.
Системное меню iOS при удержании отключено для карты (`-webkit-touch-callout: none`). На Android системный
`contextmenu`, который браузер присылает после долгого касания, не дублирует выбор.

## Архитектура

| Модуль | Назначение |
| --- | --- |
| `src/lib/geo/http.ts` | Запросы с тайм-аутом, отменой и типом ошибки: нет сети / тайм-аут / перегрузка (429) / сервер недоступен |
| `src/lib/geo/longpress.ts` | Распознавание долгого нажатия (чистая логика, покрыта тестами) |
| `src/lib/geo/geocode.ts` | Поиск (Nominatim, запасной — Photon), адрес точки (обратное геокодирование), разбор координат, ограничение 1 запрос/с к Nominatim |
| `src/lib/routing.ts` | Маршруты по дорогам: список серверов с API OSRM, перебор при сбое, альтернативы, текст манёвров, прогресс по маршруту |
| `src/lib/nav.ts` | Состояние: геопозиция, выбранная точка, цель/остановка, варианты маршрута, ведение, перестроение, сохранение маршрута между запусками |
| `src/sections/Navigation.tsx` | Карта Leaflet, жесты, карточки, камера (обзор → следование) |

### Маршрутизация

1. `routing.openstreetmap.de/routed-car` — сервер FOSSGIS (на нём работает маршрутизация openstreetmap.org).
2. `router.project-osrm.org` — демонстрационный сервер проекта OSRM (запасной).

Тайм-аут 12 с на сервер. Если сервер недоступен, ответил ошибкой 5xx или не ответил — запрос уходит на следующий.
Ответ «нет маршрута» (`NoRoute`: точка в море, на острове без парома, далеко от дорог) другим сервером не
перепроверяется и показывается как «Маршрут не найден…». Если все серверы молчат — «Не удалось построить маршрут…
Попробуйте позже или откройте внешний навигатор». Линия «по прямой» как маршрут **никогда** не рисуется; без
маршрута в карточке подписано «N км по прямой».

Альтернативы OSRM строит только между двумя точками, поэтому с промежуточной остановкой вариант один.
Время — без учёта пробок (данных о пробках у OSRM нет).

### Ведение

- Прогресс — проекция позиции на линию маршрута; манёвр, расстояние до него и остаток пути считаются локально.
- **Перестроение:** 3 точки подряд дальше max(60 м, 1,5 × точность GPS) от линии, не чаще раза в 15 с.
- **Фильтр GPS:** точки с погрешностью больше 100 м (вышки связи, туннель) не вызывают перестроение
  и «Вы прибыли». Если устройство не сообщает курс (часто в Safari), он считается по смещению.
- **Нет интернета:** при сходе с маршрута — сообщение «Нет интернета: перестрою, когда появится связь»
  (голосом тоже), уже построенный маршрут и подсказки продолжают работать; при событии `online` маршрут
  перестраивается автоматически. Тайлы карты без сети не загружаются (офлайн-карт нет).
- **Возврат из YouTube Music / ChatGPT:** цель, остановка и режим ведения хранятся в `localStorage` 6 часов;
  если iPadOS выгрузил приложение, маршрут перестраивается от текущей позиции после первой точки GPS.

## Публичные бесплатные серверы — не гарантированная инфраструктура

| Сервис | Правила | Риск |
| --- | --- | --- |
| OSRM FOSSGIS (`routing.openstreetmap.de`) | Некоммерческий сервер сообщества; разумная нагрузка, без массовых запросов | Нет SLA, возможны отказы и ограничения |
| OSRM demo (`router.project-osrm.org`) | Только демонстрация, «fair use» | Может быть перегружен/закрыт в любой момент |
| Nominatim (`nominatim.openstreetmap.org`) | ≤ 1 запрос/с, без автодополнения на каждую букву, обязательна атрибуция | Блокировка при нарушении |
| Photon (`photon.komoot.io`) | Демонстрационный сервер komoot | Без гарантий |
| Тайлы `tile.openstreetmap.org` | Атрибуция, Referer, без массовой выгрузки | При росте нагрузки — запрет |
| Overpass (АЗС, отдых) | Ограничение параллельных запросов | Тайм-ауты в часы пик |

Приложение соблюдает правила: поиск только по кнопке (без автодополнения), 1 запрос/с к Nominatim, кэш адресов
точек, нет фоновых массовых запросов. Для одного автомобиля этого достаточно; **для массового использования —
нет**.

## Архитектура для массового использования (предложение)

Ничего из этого не развёрнуто: изменения VPS и платные сервисы — только с согласия владельца.

1. **Свой шлюз** (Cloudflare Worker или отдельный сервер, не Yenota/TVoy Hub): единая точка `/route`, `/search`,
   `/reverse` для приложения; кэш (адреса — дни, маршруты — минуты), ограничение частоты по пользователю,
   переключение между провайдерами без обновления приложения. Список серверов в `PUBLIC_ROUTERS` уже
   подменяемый — шлюз станет первым элементом.
2. **Маршруты:** свой OSRM/Valhalla/GraphHopper на данных OSM для нужных стран (Украина + соседние ≈ 4–8 ГБ ОЗУ
   для OSRM car). Valhalla/GraphHopper дают альтернативы с остановками и учитывают ограничения лучше.
3. **Геокодирование:** свой Photon или Nominatim (Украина — десятки ГБ диска) — без ограничения 1 запрос/с,
   с автодополнением.
4. **Карта:** векторные тайлы (OpenMapTiles/Protomaps — один файл PMTiles на CDN) вместо растровых OSM: меньше
   трафика, чёткость на Retina, офлайн-кэш области.
5. **Пробки** доступны только у коммерческих провайдеров (HERE, TomTom, Mapbox, Google) — платно, ключ только
   на шлюзе, не в клиенте; требует согласия владельца.

## Проверено автоматически

- Unit (`tests/unit/navigation.test.ts`): долгое нажатие (порог времени, дрожание, сдвиг, второй палец, отмена,
  короткое касание), тайм-ауты и офлайн, перебор серверов маршрутов, «нет маршрута», альтернативы, URL с
  промежуточной точкой, поиск на украинском/русском, запасной поиск, адрес точки и отсутствие адреса,
  «Маршрут сюда», «Добавить остановку», выбор варианта, курс по GPS.
- Браузер (`scripts/smoke.mjs`, сенсорные события через Chrome DevTools Protocol): iPad вертикально и
  горизонтально, iPhone, iPhone горизонтально, Pixel 7 — долгое нажатие и карточка без наложений; на iPad
  дополнительно отмена сдвигом, двумя пальцами, коротким касанием и на кнопке, «Маршрут сюда» по дорогам,
  варианты, остановка, обзор → следование, «Вернуться к машине»; компьютер — правый клик. На живом сайте —
  реальные серверы и украинские адреса.

## Ограничения

- Нет пробок, полос движения, камер, ограничений скорости; время прибытия — оценка OSRM.
- Нет офлайн-карт и офлайн-маршрутов.
- На реальном iPad долгое нажатие проверено эмуляцией сенсорных событий в Chromium; поведение WebKit
  (iPadOS Safari, приложение на экране «Домой») нужно подтвердить на устройстве.
- Ведение работает, только пока приложение на экране: iPadOS не даёт веб-приложению GPS в фоне.
