# ИИ-помощник: гибридная архитектура

```
 микрофон / текст
        │
        ▼
 decideRoute()  ── управление климатом, дверями… ──► честный отказ (на устройстве)
        │
        ├── команда (маршрут, остановка, поиск, радио, тема, разделы, напоминание) ──► runTool() на устройстве
        ├── код ошибки OBD, «когда ТО»  ──────────────────────────────────────────► встроенная база
        │
        ├── облако недоступно (не подключено / локальный режим / нет сети / лимит / бюджет) ──► встроенная база + причина
        │
        └── сложный вопрос ──► askRemote(): промпт + контекст + история + TOOLS
                                   │  POST {provider, messages, tools}   (без ключей)
                                   ▼
                          server/ai-proxy (Cloudflare Worker) ── ключ ──► OpenAI или xAI Grok
                                   │  tool_calls / ответ + usage
                                   ▼
                          runTool() на устройстве → результат обратно модели (до 4 раундов) → короткий ответ
```

## Модули

| Файл | Что делает |
| --- | --- |
| `src/lib/assistant.ts` | маршрутизатор `decideRoute`, системный промпт, цикл function calling, ответы без облака, озвучивание |
| `src/lib/voiceCommands.ts` | разбор простых команд (ru/uk) — чистая функция, покрыта тестами |
| `src/lib/tools.ts` | описания и реализация инструментов — одни и те же для облака и для локальных команд |
| `src/lib/ai/context.ts` | контекст: положение (округлено, можно отключить), маршрут и манёвр, музыка, автомобиль, ТО, напоминания |
| `src/lib/ai/usage.ts` | счётчики запросов и токенов, оценка стоимости, причины блокировки облака |
| `src/lib/reminders.ts` | сервисные напоминания (дата и/или пробег) |
| `server/ai-proxy` | прокси: OpenAI и Grok, ключи в секретах, лимиты |

## Инструменты (function calling)

`navigate_to`, `search_places`, `add_stop`, `start_navigation`, `stop_navigation`, `find_along_route`, `play_radio`,
`open_music_service`, `play_music`, `media_control` (только встроенное радио), `open_section`, `open_app`,
`service_status`, `add_service_record`, `add_reminder`, `set_voice_replies`, `set_navigation_voice`, `set_theme`,
`decode_dtc`, `lookup_vehicle_knowledge`, `get_status`.

Систем автомобиля среди инструментов нет: интеграции с автомобилем нет, помощник честно отказывает.

## Что выполняется без платного API

Маршрут до адреса, остановка по пути («заедем на заправку», «додай зупинку …»), поиск места («найди …», «знайди …»),
объекты по пути, радио и пауза, тема, разделы, YouTube Music, ChatGPT, голосовые настройки, напоминания
(«напомни проверить шины», «… через 5000 км» при известном пробеге), коды OBD, срок ТО, факты базы знаний
и справочник. Любой ответ можно получить без сети — облако только расширяет.

## Расходы

- В приложении: лимит запросов в сутки (по умолчанию 60), месячный бюджет (по умолчанию $5) по ценам токенов из
  настроек, режим «Только на устройстве». Счётчики — в настройках и в строке режима помощника.
- На сервере: лимит в минуту и в сутки, предел длины ответа, модель задаёт сервер.
- У провайдера: месячный лимит в кабинете OpenAI / xAI — обязательно задать.
- Каждый раунд вызова инструментов — отдельный платный запрос; перед каждым раундом лимиты проверяются заново.

## Приватность

К провайдеру уходят: текст запроса, последние 16 сообщений диалога, контекст (округлённые координаты — можно
отключить; маршрут; музыка; автомобиль; сервисная история и напоминания) и база знаний об автомобиле.
VIN и токен приложения не передаются. Хранится всё на устройстве.

## Не проверено без ключа

Реальные ответы OpenAI/Grok (качество, задержка, точная стоимость) — до развёртывания прокси с ключом. Цепочка
приложение → прокси → инструменты проверена с имитацией сервера в браузерном тесте и unit-тестами прокси.
